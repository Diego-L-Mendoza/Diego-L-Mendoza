## About Me

I'm a Computer Science student at the University of Central Florida who likes the part of ML that happens *after* the notebook: making models fast, measurable, and trustworthy once they leave the lab.

Right now I do turbulence-modeling research at **UCF HyperSpace**, where I built a NumPy PIV pipeline that runs **25x** faster and an Optuna + PyTorch framework for tuning SHRED models across 11 datasets.

Outside of work I build systems tools like **ModelRelic**, a C++20 model registry and ONNX Runtime benchmarking engine, and I compete at hackathons (ShellHacks, KnightHacks, CalHacks).

## Featured Projects

| Project | Description |
|---|---|
| **ModelRelic** *(private repo)* | C++20 model registry with content-addressed storage and lineage, plus an ONNX Runtime engine that benchmarks latency, throughput and memory on CPU and CUDA |
| [**CollideAverse**](https://devpost.com/software/collideaverse) ([code](https://github.com/pr1ncesspink/ShellHacks_2026)) | ShellHacks 2026: checks construction and utility plans for collisions. I built the FastAPI backend on Cloud Run and the Google ADK/A2A agents |
| [**ShadeSmith**](https://github.com/Bousef/shadesmith) | ShellHacks 2025: turns an image into paint-mixing recipes using parallel A2A agents with Gemini, served from Flask on Cloud Run |
| [**Factory Wi-Fi Anomaly Detection**](https://github.com/Diego-L-Mendoza/metil-research-project) | ns-3 digital twin of a wireless factory network, with Isolation Forest flagging 100% of misbehaving devices |
| **EmberFlow** *(senior design, in progress, private)* | Edge computing for wildfire smoke detection that notices when a camera's detections stop being trustworthy and responds with shadow deployments and rollbacks |
